# 🌐 Gaurav Joshi - Personal Portfolio Website

A modern, responsive, and recruiter-friendly personal portfolio website built using **HTML5** and **CSS3** only.

This portfolio is designed to showcase skills, projects, education, certifications, and contact information in a professional way suitable for:

- LinkedIn Portfolio
- GitHub Pages
- Placement Interviews
- Developer Showcase

---

# 🚀 Features

✅ Fully Responsive Design  
✅ Modern Dark Theme UI  
✅ Smooth Hover Animations  
✅ Gradient Hero Section  
✅ Timeline Style Education Section  
✅ Stylish Skill Progress Bars  
✅ Professional Project Cards  
✅ Certifications Section  
✅ Resume Download Button  
✅ Recruiter-Friendly Layout  
✅ Beginner Friendly Code Structure
